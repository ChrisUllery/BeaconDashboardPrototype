FOR THE BEACON EDITORS

How to use

  1. For an interactive map with a race selector, use Copy all-races iframe in the first section. Readers can choose any of the 15 races, including on mobile.
  2. To feature one specific race, find it below. Choose Precinct results, County results (where available) or District overview.
  3. Click Preview map to check how the interactive map looks. Only one map preview is loaded at a time.
  4. Click Copy iframe code. In WordPress, add a Custom HTML block where the map should appear and paste the code.
  5. Repeat for any other races you want to feature. Preview the WordPress post to confirm the iframes display correctly.

Iframe code points to the published GitHub Pages map viewer; local previews use your PyCharm server. Publish the map viewer and data before placing these embeds in a live article. Some WordPress roles or configurations restrict iframe HTML.
