FOR THE BEACON EDITORS

How to use

  1. Choose Before polls close or After polls close under Article introduction. Click Copy introduction and paste those paragraphs at the top of your WordPress story.
  2. For each race you want to highlight, click Copy heading and introduction. Paste that text into the story.
  3. Click Copy iframe code for the same race. Add a Custom HTML block in WordPress directly below the race's introduction, then paste the iframe code.
  4. Repeat the heading, introduction and embed steps for the remaining races you want to include.

Or build the full article in one paste

Copy the selected article introduction, all 15 race headings and introductions, and all 15 card embeds as one HTML snippet. Paste it into one Custom HTML block in WordPress, not a regular paragraph block. You can remove any races you do not want afterward.

Before publishing, verify the copy and confirm that real election returns have replaced the simulated data. Preview the WordPress post to make sure its iframe embeds are permitted and displayed correctly.
